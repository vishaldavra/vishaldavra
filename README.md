<h2 align="center">💫 About Me</h2>

<p align="center">
  Passionate <b>Full-Stack Architect & Cross-Platform Engineer</b> specialized in crafting high-concurrency systems, enterprise business solutions, and fluid mobile applications.
</p>

- 🏏 **Flagship Project — [CrickBoss](https://github.com/vishaldavra/crickboss)**: Advanced real-time Cricket Auction, Bidding Engine & Fantasy Sports Platform built with high-throughput Python backend and reactive TypeScript/React frontend.
- 🏭 **Industrial Suite — Mansi Metals Ecosystem**: Complete integrated enterprise suite featuring Flutter Mobile Apps ([`Mansi_Metals_AC`](https://github.com/vishaldavra/Mansi_Metals_AC)), Desktop PC Client ([`Mansi-Metal-PC`](https://github.com/vishaldavra/Mansi-Metal-PC) in C# / .NET), Web Portal ([`Mansi_Metals_Web`](https://github.com/vishaldavra/Mansi_Metals_Web)), and REST API backend.
- 📱 **Mobile & Cross-Platform**: Creating production-grade, pixel-perfect mobile applications using **Flutter & Dart**, alongside native Android experiences in **Kotlin**.
- ⚡ **Backend & Scalability**: Designing low-latency RESTful APIs and real-time WebSocket pipelines with **FastAPI / Python**, **Node.js**, and **ASP.NET Core / C#**.
- 🛠️ **Systems & Infrastructure**: Deploying containerized microservices with **Docker**, caching layers with **Redis**, automated CI/CD workflows, and Linux server management.
- 💬 **Ask me about**: Full-Stack Architecture, Flutter state management, Python APIs, real-time engines, and database design.
